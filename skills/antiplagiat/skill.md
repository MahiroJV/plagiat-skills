# antiplagiat

A comprehensive diagnostic and rewriting workflow to evaluate written material for indicators of machine generation and plagiarism, followed immediately by an improved, natural, and original version of the text.

## Summary

This skill screens written content for signs of synthetic generation (such as monotonous burstiness, low perplexity, formulaic transitions, and telltale LLM phrases) and checks for verbatim matches across public web sources. Whenever issues are detected, it automatically delivers a rewritten, humanized version that eliminates AI markers and plagiarized phrasing while preserving the original meaning.

## When to Use

- The user asks whether a text, essay, article, or document was generated by AI or an LLM.
- The user asks to check a document or submission for plagiarism, copied text, or missing attributions.
- The user requests an originality review or authenticity audit before publishing or submitting content.
- The user wants both a diagnostic check and an immediate improved rewrite of flagged passages.

## Workflow Steps

### 1. Structural & Stylistic AI Profiling

Analyze the submitted text across core synthetic writing markers:

- Sentence cadence and burstiness: Check whether sentence lengths, clauses, and paragraph structures are uniform and predictable rather than dynamically varied.
- Vocabulary and hallmark phrasing: Flag overrepresented LLM clichés across languages (e.g., "delve", "testament to", "it is worth noting", "crucial role", "navigating the landscape of", "rich tapestry", or rigid mechanical transitions).
- Generic abstraction: Notice if paragraphs speak in high-level truisms, repetitive restatements, or broad summaries instead of citing concrete examples or precise data.
- Balanced hedging: Look for overly diplomatic, formulaic "On one hand... on the other hand" structures that avoid taking a clear angle.

### 2. Plagiarism & Verbatim Matching

Screen for uncredited duplication across public sources:

- Extract distinctive phrases: Identify 2-4 unique, specific strings of 6 to 10 consecutive words that carry the core factual claim or argument.
- Run exact-match web searches: Use `google:search` with the extracted phrases wrapped in quotation marks to check for indexed public publications.
- Verify source context: If matches appear, inspect source pages using `google:browse` to verify publication dates, authorship, and whether the text was properly credited.

### 3. Diagnostic Report Generation

Format the initial findings into a clear, scannable report:

- Authenticity & Originality Summary: Provide an overall evaluation (Likely Human, Mixed / Edited AI, Highly Likely AI Generated) along with a Plagiarism Risk assessment (Clear, Possible Paraphrase, Direct Verbatim Match).
- Flagged Passages & Evidence: Quote specific sentences and explain why each was flagged (exact web match, formulaic repetition, or artificial cadence).
- Source Attribution: If web matches are located, provide clickable markdown links to the exact source URLs.

### 4. Automatic Rewrite & Humanization

Immediately following the diagnostic report, provide an improved version of the flagged text (or the full text if predominantly flagged):

- Vary sentence rhythm: Mix short, direct statements with longer, multi-clause sentences to establish natural human cadence.
- Remove AI clichés and filler: Replace mechanical transitions and inflated phrasing with clear, active verbs and natural flow.
- Eliminate verbatim overlap: Restructure any copied or closely paraphrased segments from the ground up while keeping factual claims, technical terms, and core arguments intact, adding proper inline attribution where appropriate.
- Key Improvements Note: Briefly list 2-3 specific adjustments made in the rewritten version so the user can see how the issues were resolved.

## Gotchas

- Avoid absolute certainty: AI detection heuristics are probabilistic. Frame diagnostic findings as stylistic patterns and likelihoods rather than conclusive proof.
- Account for ESL and academic writing: Non-native writers and standard academic formats often use rigid transition markers that can resemble AI cadences. Base evaluations on multiple overlapping indicators.
- Preserve factual meaning during rewriting: Never invent facts or alter technical definitions when humanizing or rephrasing the text.
- Search with precision: Never paste full paragraphs into search queries. Search only short, distinctive quoted phrases (6-10 words) to avoid query noise.
